下面给你一份“**做播放器（解封装/解码/重采样/缩放/同步/渲染）**最值得掌握并重封装的 FFmpeg 结构/对象清单”。我按模块分层，你可以按顺序逐个吃透；每个条目我都标出它在流水线里的位置与封装重点。

# 1. 容器层（Demux）
- **`AVFormatContext`**
  - **角色**：容器输入上下文（打开文件/网络流、维护 streams、读包）。
  - **封装重点**：`avformat_open_input` / `avformat_find_stream_info` / `av_read_frame` / `avformat_close_input`；明确 ownership（是否接管指针）。
- **`AVStream`**
  - **角色**：每一路流（视频/音频/字幕）的描述；含 `time_base`、索引、`codecpar`。
  - **封装重点**：只读视图即可；最关键是 `time_base`、`avg_frame_rate`、`r_frame_rate`、`codecpar`。
- **`AVCodecParameters`（`stream->codecpar`）**
  - **角色**：流的编码参数（codec_id、分辨率、采样率、声道布局等）。
  - **封装重点**：作为“初始化解码器上下文”的输入；通常不需要 RAII（由 stream 持有）。

# 2. 解码层（Decode）
- **`AVCodec`**
  - **角色**：解码器本体（查找 decoder 用）。
  - **封装重点**：通常只是裸指针引用（不需要释放）。
- **`AVCodecContext`**
  - **角色**：解码器实例/状态机（send/receive）。
  - **封装重点**：`avcodec_alloc_context3` / `avcodec_parameters_to_context` / `avcodec_open2` / `avcodec_send_packet` / `avcodec_receive_frame` / `avcodec_free_context`；**必须把 `EAGAIN/EOF` 当成状态而不是错误**。
- **`AVPacket`**
  - **角色**：压缩数据包（demux 输出，喂给解码器）。
  - **封装重点**：`av_packet_alloc/free`、`av_packet_unref`、`av_packet_ref`；区分“对象结构体生命周期”和“内部 buffer 引用计数”。
- **`AVFrame`**
  - **角色**：解码后原始帧（视频像素或音频采样），最终用于渲染/同步。
  - **封装重点**：`av_frame_alloc/free`、`av_frame_unref`、`av_frame_ref`；掌握时间戳字段（优先 `best_effort_timestamp`）、视频 `data/linesize`、音频 planar/packed、`nb_samples` 等。

# 3. 时间与同步（必须掌握的“非对象”概念，但强相关）
- **`AVRational` / `time_base`**
  - **角色**：时间戳的单位系统。
  - **封装重点**：统一用 `av_rescale_q` 做整数换算；避免 double。
- **时间戳字段（在 `AVPacket`/`AVFrame` 上）**
  - **封装重点**：理解 `pts/dts` 与 `frame->best_effort_timestamp` 的关系；同步/显示以 frame 为准。

# 4. 视频处理链（可选但播放器通常会用）
- **`SwsContext`（libswscale）**
  - **角色**：像素格式转换/缩放（如 YUV420P → RGB 或统一成某种渲染格式）。
  - **封装重点**：`sws_getContext` / `sws_scale` / `sws_freeContext`；以及输出缓冲的管理（配合 `av_image_alloc`/`av_image_fill_arrays`）。
- **`AVPixFmtDescriptor`（了解即可）**
  - **角色**：像素格式描述（调试/格式判断用）。

# 5. 音频处理链（你后面用 SDL 必会用到）
- **`SwrContext`（libswresample）**
  - **角色**：重采样/重布局/格式转换（比如转成 `S16`/立体声/48k）。
  - **封装重点**：`swr_alloc_set_opts2`（或旧 API）/ `swr_init` / `swr_convert` / `swr_free`；掌握输入输出的采样格式、声道布局、采样率。
- **音频相关结构概念（在 `AVFrame` 内）**
  - **重点字段**：`nb_samples`、`sample_rate`、`ch_layout`（新 API）或 `channel_layout`（旧）、`format`（sample fmt）、`data[]`（planar/packed）。

# 6. 元数据/参数（用到再封装）
- **`AVDictionary`**
  - **角色**：options 参数（open2/open_input 等）。
  - **封装重点**：`av_dict_set` / `av_dict_free`；RAII 很值得做，避免泄漏。
- **`AVIOContext`（进阶）**
  - **角色**：自定义 IO（内存流、加密流、特殊数据源）。
  - **封装重点**：后面你做网络/自定义数据源再考虑。

# 7. 调试/日志/错误设施（你现在正卡在这里）
- **错误码处理（你的 `AVError/FFmpegStatusDetail`）**
  - **封装重点**：提供 `is_eagain()` / `is_eof()` / `is_fatal()` 这种语义函数，避免把状态机信号当错误。
- **`av_err2str` / `av_strerror`**
  - **角色**：错误码转字符串（日志必备）。

---

## 推荐你“学习/重封装”顺序（最省时间）
1. `AVError/FFmpegStatusDetail`（先把 EAGAIN/EOF 语义做对）
2. `AVPacket` / `AVFrame`（ref/unref/alloc/free + 时间戳字段）
3. `AVCodecContext`（send/receive 状态机）
4. `AVFormatContext` / `AVStream`（time_base 与读包）
5. `SwrContext`（音频）
6. `SwsContext`（视频转换，按需）
